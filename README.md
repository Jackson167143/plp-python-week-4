# Grade Reporter & Bug Hunt

This assignment practices Python loops, conditions, running totals, and debugging.

## Files

* `grade_reporter.py` - Uses a for loop and if/elif/else statements to calculate grades, pass and fail counts, and the average score.
* `bug_hunt.py` - Finds and fixes three bugs in a while loop program that calculates the sum of numbers 1 to 5.

## Bug Hunt Reflection

The hardest bug to find was the `count < 5` condition because it did not produce an error message. I knew something was wrong because the program did not give the required answer of 15. I changed the condition to `count <= 5` so that the loop would include the number 5.

# PLP Python Week 4

This repository contains my PLP Python Week 4 assignment.

- `welcome.py` - Uses a welcome() function to greet three people.
- `toolbox.py` - Contains three functions: double(), is_pass(), and greet().

The hardest function to write was `greet()` because it uses an optional greeting parameter. I had to make sure the default value "Hello" was used when no greeting was provided.
